# Mis Horas · Ana Paola

Control de horas trabajadas y pagos. App web (GitHub Pages) con Firebase (Auth + Firestore + Cloud Messaging).

- `index.html`: la app.
- `firebase-messaging-sw.js`, `manifest.json`, iconos: instalación en el móvil y notificaciones.
- `scripts/avisos.js` + `.github/workflows/avisos.yml`: avisos automáticos cada 15 minutos.
